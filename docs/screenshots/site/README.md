# The site

Every picture is the real page, served by `next dev` and taken by
`scripts/screenshots/run.mjs`, signed out unless it says otherwise, at 1440
wide (the whole page when it is long) and a few at 390. The account shown is
Maya Collins, made up for these pictures. The site is dark throughout, so
every page is on near black from the navbar to the footer.
